# 既存UI拡張の確認範囲

この対応は、実店舗でのブラウザ注文に向けた既存アプリの不具合修正と、仕様が決まったスタッフ受付機能の追加です。既存の赤・温かい白・React Nativeの操作体系を引き継ぎます。新しいブランドやビジュアル世界の選定は依頼範囲に含めないため、独立したPRODUCT.md・デザイン方向の選択・FORM seedは使用しません（既存世界の機能拡張としての適用範囲）。

画面の役割は、カテゴリから料理を選ぶ、お客様が翻訳モードと生成状態を識別する、スタッフが注文と要望を確認して次の状態へ進める、の3点です。スタッフ画面はデスクトップで一覧と詳細を並べ、スマホでは詳細から一覧へ戻る構造です。原文・参考訳の表示は比較対象の完成訳と区別します。

確認は合成データのWebビルドを1280×900・390×844で撮影して行います。日本語フォントを備えた環境を使います。機械的なUI検査は変更した6画面に1回実行し、指摘はありませんでした。その後の画像レビューで見つかったカテゴリ領域の伸長、翻訳状態の省略、追加操作の文字コントラストを同じ確認範囲で修正しました。修正後の同じ6画像を独立レビューし、指摘の解消と可視の回帰がないことを確認しました。

実店舗のメニュー画像・長文・端末・公開URLの確認、および翻訳の言語的評価は別途必要です。新しい表現や装飾を増やすための継続的な調整は行いません。
