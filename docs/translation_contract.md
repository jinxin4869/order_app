# 翻訳の生成・比較

単発・一括翻訳は同じ処理を使います。数字と空白だけの入力は変更せず、1文字の日本語も翻訳します。

辞書の語を原文の文字位置で特定し、長い複合語を優先して重複を除きます。辞書の英語・中国語訳をXMLタグで保護してDeepLへ渡します。DeepLの返却値でタグと訳語が保たれていることを確認してから取り出します。表記揺れは完全一致・かな・登録済みの読みだけを対象とし、似ているだけの別の料理へ置換しません。

使用するAPIオプションは[DeepL SDKの公式説明](https://github.com/DeepL/deepl-node#text-translation-options)の`tagHandling: xml`と`ignoreTags`です。実APIによる自然さ・食材やアレルゲンの正確さの評価は別途必要です。テストでは合成の翻訳応答を使用します。

`method`は辞書適用済みの`hybrid`、通常の`deepl_api`、辞書なしの`deepl_only`、数字の`passthrough`を区別します。`usedDictionary`と`foundTermsCount`は実際に適用した箇所を表します。キャッシュでも元の方法を保持し、`fromCache`だけを変更します。キャッシュは言語・モード・方式バージョン・適用辞書の内容で分離します。辞書読み込みのメモリキャッシュは最長5分です。

単発翻訳でAPIが失敗し辞書だけで一部を置換できた場合は、`status: partial`、`method: dictionary_fallback`を返します。日本語が残り得る参考訳のためキャッシュしません。表示は「原文を含む参考訳・比較不可」とし、完成した訳として扱いません。設定不足、辞書なしのAPI失敗、置換できない失敗はエラーを返します。

一括翻訳は設定不足・API失敗・保護タグの欠落で失敗し、メニューの更新を確定しません。原文や辞書ありの訳を辞書なしフィールドへ代入しません。
